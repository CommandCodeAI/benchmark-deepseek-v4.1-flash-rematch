Build a single-file index.html (inline CSS and JS, no build step, no external libraries or network requests) containing an evolving ecosystem simulation of plants, prey, and predators on a 2D grid. It must auto-start on page load and run for N generations on its own. Each creature carries a gene vector (speed, vision, metabolism, reproduction threshold) or a tiny neural net that mutates on reproduction. Use a seeded PRNG for all randomness so the same seed always reproduces the same run, and keep the simulation logic separate from rendering so it can also run headless and faster than real time.  The design is the main deliverable. Treat the simulation as a living specimen under glass, and make the controls part of the composition rather than a form beside it. Pick one distinctive visual direction suited to the subject (for example a naturalist’s field journal, a bioluminescent deep-sea observatory, or a scientific plate), with a deliberate palette, a considered type pairing, and one memorable signature element. Give each species its own color and glyph language. Put every variable (seed, mutation rate, food regrowth, generations, speed, catastrophe intervals) in an integrated control surface, such as a collapsible side drawer, a docked instrument panel, or controls anchored to the world itself. Use custom-styled sliders, dials, steppers, and toggles with live value readouts, units, and sensible ranges. Add a small sparkline next to each knob showing its effect, and give each control tooltips, keyboard support, and visible focus states. Changes should apply live with smooth feedback.   Add a scheduled catastrophe system (drought, plague, and one of your choosing) that fires automatically at configurable intervals. Announce each event with a restrained, on-theme visual moment, such as a screen tint, a banner, or a timeline marker, and mark it on the charts. When the run ends, transition into a polished dashboard with population curves and trait-drift charts (mean and spread per gene per species), all drawn on canvas in the same visual language.
