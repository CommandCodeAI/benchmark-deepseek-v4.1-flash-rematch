Naz's run: not a stock benchmark

His Round 1 post reports a failed CommandCode GOAT run with 91 failed calls. His own session files show image input on, 92 screenshots resent on every request (up to ~20 MB each) and 3 concurrent Agent Teams agents. "2h 28m 04s" is a helper agent he stopped by hand after the build had already failed, and the TTFT numbers were computed by the agent itself, retries included. With no screenshots in context, his run had 0 failures and a 3.9s P50 TTFT. We're hardening the API for heavy image payloads anyway.
